# Customer Segmentation Analysis

## 📊 Project Overview
This project focuses on segmenting customers based on income and spending behavior to identify high-value groups.

## 🛠 Tools Used
- Python (Pandas, Matplotlib)
- Data Analysis & Segmentation Techniques

## 📈 Key Analysis
- Created customer segments based on income and spending score
- Identified high-value and low-income groups
- Analyzed average spending per segment

## 🔍 Key Findings
- High-income customers with high spending form the most valuable segment
- Low-income customers show lower engagement
- Mid-value segment has potential for growth strategies

## 📁 Project Structure
- `data.csv` → dataset
- `analysis.py` → analysis script

## 🚀 Business Impact
Customer segmentation helps companies:
- Target marketing campaigns effectively
- Improve customer retention
- Optimize revenue strategies
